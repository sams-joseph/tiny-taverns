# Domain Docs

This is a single-context repo.

## Before exploring, read these

- `CONTEXT.md` at the repo root for the Tiny Taverns domain glossary.
- `docs/adr/` for architectural decisions that affect the area being changed.

## Rules

- Use the glossary's vocabulary in issue titles, PRDs, tests, and implementation notes.
- Prefer **Campaign**, **Assistant Conversation**, **Campaign Session**, **NPC**, **Campaign Note**, and **Campaign Update Proposal** over avoided synonyms.
- If a proposed change contradicts an ADR, surface the conflict explicitly rather than silently overriding it.
