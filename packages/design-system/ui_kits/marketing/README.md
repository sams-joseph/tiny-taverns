# UI kit — marketing site

One long homepage, `Site.jsx`, composed of `SiteHeader`, `Hero`, `Features`,
`Quote`, `Pricing`, `Signup` and `SiteFooter`.

**Rhythm.** Dark / light / light / sunken / light / dark / dark. Never two dark
sections touching except the closing signup + footer pair, which read as one block.

**The hero is the product.** Instead of an illustration, the hero shows a real
initiative list built from the same primitives as the app. The source repo shipped
no imagery, so no photographs or illustrations are used anywhere on this page —
see the root readme for what to supply.

**Interactive:** the signup form swaps to an emerald confirmation on submit. The sticky
header uses `rgba(245,248,250,.86)` + `blur(10px)` — the only blur on the site.
