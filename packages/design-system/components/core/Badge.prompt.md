Small status chip on shadcn's `variant` API, plus `success` / `magic` / `info` for table semantics.

```jsx
<Badge variant="destructive">Hostile</Badge>
<Badge variant="magic">Concentrating</Badge>
<Badge variant="outline">CR 4</Badge>
```

`default` and `destructive` are solid fills; the semantic variants are soft tints with matching ink, which keeps a row of badges calm. Sentence case, 12px medium.
