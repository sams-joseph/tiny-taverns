Dark hard-bordered message box with a filled glyph strip down the left — deliberately shaped like an RPG dialogue box.

```jsx
<Toast variant="success">
  <ToastTitle>Goblin scout downed</ToastTitle>
  <ToastDescription>Removed from initiative.</ToastDescription>
</Toast>
```

Variants: `default` (verdigris) / `destructive` / `success` / `magic`. One at a time, bottom-right; slides 10px in from the right and fades.
